# Готовые промпты для Codex и Antigravity

## Codex — ревью backend

```text
Проанализируй текущий проект ToiMatch AI.
Проверь backend-логику в app/: dataset loading, hard filters, scoring, recommender.
Не меняй UI и README.

Цель: гарантировать выполнение требований кейса:
- занятый подрядчик не попадает в выдачу;
- категория в городе отсутствует → category_not_found;
- категория есть, но никто не подходит → no_eligible_candidates;
- максимум 3 результата;
- одинаковый запрос → одинаковый порядок;
- max_hours=None корректно трактуется как “не применимо”.

Добавь или улучши тесты, если найдёшь слабые места.
Запусти pytest -q и покажи результат.
```

## Antigravity — QA и demo

```text
Ты QA и demo-engineer проекта ToiMatch AI.
Не переписывай recommender architecture.

Задачи:
1. Запусти scripts/audit_dataset.py и проверь распределение категорий.
2. Запусти scripts/find_demo_cases.py.
3. Найди 4 лучших demo-запроса:
   - плотная категория;
   - редкая категория;
   - no result;
   - одинаковый запрос на две разные даты.
4. Проверь, что explanations не являются общими фразами.
5. Проверь Streamlit UI вручную.
6. Обнови demo/demo_cases.json при необходимости.

В конце дай краткий список сценариев для live-demo.
```
