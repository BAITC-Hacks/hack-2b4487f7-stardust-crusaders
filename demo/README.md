# Demo cases

Сценарии в `demo_cases.json` построены скриптом `scripts/find_demo_cases.py`
только на основе `data/hackathon_dataset_anonymized.csv`.

## Генерация

Из корня репозитория выполните:

```bash
python scripts/find_demo_cases.py
```

Скрипт заново проверяет каждый запрос через текущий recommender и сохраняет
ожидаемый статус и IDs результатов. Если подходящий сценарий не найден, скрипт
завершается с ошибкой, а не создаёт выдуманные данные.

## Что показывать жюри

- `dense_category`: большая категория, несколько кандидатов и ranking;
- `rare_category`: небольшая категория и реальный размер выдачи;
- `no_result`: существующая категория, но бюджет отсекает весь pool;
- `date_comparison`: одинаковые условия на две даты, где busy dates меняют выдачу.
